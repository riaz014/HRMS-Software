Dashboard: HRMS Control Center

The dashboard gives a real-time overview of HR operations and quick navigation to all modules.

How to use it

  1. Open the Dashboard from the top menu.
  2. Review the stat cards at the top for employee count, active payroll, and pending reviews.
  3. Click any stat card to jump directly to the related module.
  4. Use the module cards to open Employee, Salary, or Payroll workflows quickly.

When to use

Use this page at the start of each day to monitor status and access the next task with one click.

Employee Management

Manage employee records including adding new staff, updating details, and searching/filtering records.

Common tasks

  1. Click Add Employee to create a new employee profile.
  2. Fill required fields carefully: employee number, full name, department, designation, and contact data.
  3. Use search and filter controls to find employees quickly.
  4. Use edit to update profile data and keep records current.
  5. Deactivate records when employees are no longer active.

Best tip

Always verify employee number uniqueness before saving to avoid payroll conflicts.

Salary Management

Define and maintain salary structures that payroll generation depends on.

How to set salary correctly

  1. Open Salary Management from the navbar.
  2. Select employee and enter base salary, bonuses, and allowances.
  3. Set effective date ranges for each salary revision.
  4. Save the record and verify it appears in the salary list.
  5. Update salary records when compensation changes.

Important note

Payroll generation may skip employees with missing salary records, so keep salary data complete.

Open Salary Management

Payroll Dashboard

Generate monthly payroll, load period-wise reports, and export individual payslips.

End-to-end monthly payroll flow

  1. Set payroll inputs: year, month, tax %, additional bonus, and additional deductions.
  2. Click Generate Monthly Payroll.
  3. After generation, click Load Monthly Report to refresh totals for the selected month.
  4. Review Transactions, Gross Total, Deductions Total, and Net Total.
  5. Use Export to PDF in Recent Payments to download individual payslips.

Troubleshooting

If report totals look empty, confirm employees have salary records and the selected period is correct.

Open Payroll Dashboard

Activity Log

Track key actions across HRMS modules for audit and operational visibility.

How to analyze activity

  1. Use search to find actions by employee, user, or action keyword.
  2. Filter by module to isolate Employee, Salary, Payroll, or System events.
  3. Filter by status to focus on success, pending, or error actions.
  4. Use Clear Filters to reset and view complete history again.

Access control

This page is visible to Admin users for oversight and audit workflows.

Open Activity Log

Best Practices for Smooth HRMS Usage

  • Update employee and salary records before generating payroll each month.
  • Use the dashboard cards for quick navigation instead of opening pages manually.
  • Run payroll report after generation to verify totals before exporting payslips.
  • Review activity logs regularly to detect failed actions early.
  • Log out after use, especially on shared systems.
